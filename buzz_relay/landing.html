Setup Instructions

The Buzz relay is running. To use it with Hermes agents:

BUZZ_RELAY_URL=ws://localhost:3001
BUZZ_PRIVATE_KEY=<nsec...>

# Generate a keypair for each agent:
buzz-admin generate-key

# Register the agent as relay member:
buzz-admin add-member --pubkey <agent_pubkey>

# Create a channel:
buzz channels create --name "group-chat" --type stream --visibility open

Then connect Hermes via the Buzz gateway adapter or buzz-acp.
